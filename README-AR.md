# محرر كتالوج OMERA

موقع عربي يعمل من المتصفح لإنشاء كتالوجات التصنيع والتشطيب بتصميم A4، مع إمكانية تعديل النصوص والجداول، استبدال الصور والشعار، إدارة الصفحات، والحفظ بصيغة PDF.

## التشغيل على جهازك مجانًا

يلزم تثبيت Node.js إصدار 22 أو أحدث، ثم افتح مجلد المشروع في الطرفية وشغّل:

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية. لا يحتاج الموقع إلى قاعدة بيانات خارجية أو اشتراك مدفوع؛ تُحفظ المشاريع محليًا داخل المتصفح.

## الاستخدام

- عدّل أي نص مباشرة من الصفحة أو من لوحة الخصائص.
- اضغط على أي مساحة صورة لرفع صورة بديلة من جهازك.
- استخدم زر العين بجوار أي خانة في لوحة الخصائص لإخفائها من الصفحة، واضغطه مرة أخرى لإظهارها.
- افتح «إعدادات الهوية» لتغيير الشعار وبيانات الشركة والألوان.
- استخدم «صفحة جديدة» لإضافة غلاف أو منتج أو رسم فني أو خامات أو مخطط أو صفحة حرة.
- اضغط «حفظ PDF» ثم اختر **Save as PDF / حفظ كملف PDF** من نافذة الطباعة.
- استخدم زر نسخة JSON في الشريط العلوي لحفظ نسخة احتياطية يمكن استيرادها لاحقًا.

## أوامر الفحص

```bash
npm run build
npm test
```

## ملاحظات مهمة

- يفضّل استخدام Chrome أو Edge للحصول على أفضل نتيجة في الطباعة.
- صورة الغلاف تملأ مساحتها تلقائيًا بلا إطار، ويُقص الجزء الزائد عند اختلاف نسبة أبعاد الصورة.
- فعّل خيار طباعة رسومات الخلفية عند الحفظ كـ PDF للمحافظة على الألوان والزخارف.
- امسح بيانات الموقع من المتصفح فقط إذا كنت تريد حذف النسخ المحفوظة محليًا.
